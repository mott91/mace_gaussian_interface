# Research Summary: v1.2 Analysis Quality Overhaul

**Domain:** IR spectroscopy analysis pipeline improvements
**Researched:** 2026-03-28
**Overall confidence:** HIGH (most features are well-understood; NIST integration is MEDIUM)

## Executive Summary

The v1.2 milestone adds five capability areas to the existing MACE-Gaussian analysis pipeline: Lorentzian spectral broadening, experimental spectra comparison via NIST, degenerate mode handling, wall-clock timing instrumentation, and VPT2 alternative investigation.

The good news: most of these features require **zero new dependencies**. Lorentzian broadening is a 10-line numpy function. Degenerate mode handling is an algorithmic fix to existing mode matching. Timing instrumentation extends the existing `time.perf_counter()` pattern. Only NIST experimental comparison needs new packages: `nistchempy` (1.0.5) for fetching spectra and `jcamp` (1.3.0) for parsing JCAMP-DX files.

The VPT2 alternative investigation is the highest-risk item. PyVPT2 is **incompatible** -- it hard-depends on Psi4 and cannot consume external force constants. Psience (McCoy Group) is a possible candidate but needs a hands-on spike to verify it can ingest Gaussian-format force constants. Recommendation: defer VPT2 alternatives to a time-boxed spike, don't block v1.2 on it.

The critical ordering insight: Lorentzian broadening must come first because NIST experimental overlay depends on it for visual comparison. Degenerate mode handling and zero-intensity filtering should precede the analysis pipeline overhaul. Timing is independent and can be done in parallel.

## Key Findings

**Stack:** Only 2 new pip packages needed: `nistchempy>=1.0.5` and `jcamp>=1.3.0`. Everything else uses existing deps.

**Architecture:** Three new modules: `spectral_broadening.py` (Lorentzian), `experimental_comparison.py` (NIST fetch + JCAMP parse + overlay), and `PipelineTimer` utility class. All integrate into existing analysis workflow.

**Critical pitfall:** NistChemPy is a web scraper, not an official API. Must rate-limit requests, cache results locally, and handle graceful failures when compounds lack IR data or NIST changes their HTML.

## Gaps to Address

- **NistChemPy hands-on testing:** Does `compound.ir_specs` actually return downloadable JCAMP-DX? What format exactly? Need to test with water, ethanol, methane before building the pipeline.
- **Psience VPT2 force constant ingestion:** Can `VPTSystem` accept pre-computed Hessian + cubic/quartic from Gaussian .fchk? Needs 2-hour spike.
- **NIST coverage for benchmark molecules:** Which of the ~25 planned benchmark molecules have gas-phase IR spectra in NIST? Need to check before committing to experimental comparison as a thesis feature.
- **Spectral similarity metrics:** SID/SIS scores (Laurens et al. JCTC 2020) vs simple Pearson correlation of broadened spectra -- which is standard in the ML+spectroscopy literature? Need to check 2-3 recent papers.
