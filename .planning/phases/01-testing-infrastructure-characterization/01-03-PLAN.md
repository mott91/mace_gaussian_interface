**Do NOT import or test `convert_chk_to_fchk` or `get_fchk_from_chk`** -- these require Gaussian's `formchk` command. Unit tests must not depend on Gaussian. All tests use pre-committed .fchk files.

**Test 1: test_extract_modes_water(water_dft_fchk)**
- Call `extract_modes_from_fchk(water_dft_fchk, force_harmonic=True)`
- Assert returns tuple of 5 elements: (modes, frequencies, coords, masses, n_atoms)
- Assert `n_atoms == 3` (water has 3 atoms: O, H, H)
- Assert `modes.shape == (3, 3, 3)` (3 modes, 3 atoms, 3 xyz)
- Assert `frequencies.shape == (3,)`
- Assert `coords.shape == (3, 3)`
- Assert `masses.shape == (3,)`
- Assert all frequencies > 0 (no imaginary modes)
- Assert oxygen mass ~15.999 (`masses[0]` should be approx 15.999, but check atom ordering in fchk)
- Assert hydrogen masses ~1.008

**Test 2: test_extract_modes_ch4(ch4_dft_fchk)**
- Call `extract_modes_from_fchk(ch4_dft_fchk, force_harmonic=True)`
- Assert `n_atoms == 5` (CH4: C + 4H)
- Assert `modes.shape[0] == 9` (3*5-6 = 9 vibrational modes)
- Assert `modes.shape == (9, 5, 3)`
- Assert all frequencies > 0

**Test 3: test_modes_are_normalized(water_dft_fchk)**
- Extract modes from water fchk
- For each mode, compute `np.linalg.norm(mode.flatten())`
- Assert the norm is approximately 1.0 (Gaussian normal modes are mass-weighted and normalized, but check if this holds for the fchk format -- if not, adjust assertion to just check norm > 0)
- NOTE: Mode normalization convention may vary. If norms are not 1.0, document the actual convention and test that norms are consistent (all similar magnitude).

**Test 4: test_parse_fchk_section_real(water_dft_fchk)**
- Read the fchk file content as string
- Call `parse_fchk_section(content, 'Real atomic weights', 'R')`
- Assert returns numpy array of length 3 (water has 3 atoms)
- Assert values are approximately [15.999, 1.008, 1.008] (oxygen, hydrogen, hydrogen -- but verify actual ordering)

**Test 5: test_parse_fchk_section_integer(water_dft_fchk)**
- Read fchk content
- Call `parse_fchk_section(content, 'Atomic numbers', 'I')`
- Assert returns array with values [8, 1, 1] (O=8, H=1, H=1)

**Test 6: test_parse_fchk_section_missing(water_dft_fchk)**
- Read fchk content
- Assert `parse_fchk_section(content, 'Nonexistent Section', 'R')` raises `ValueError`

**Test 7: test_extract_modes_file_not_found**
- Assert `extract_modes_from_fchk("nonexistent.fchk")` raises `FileNotFoundError`

**Test 8: test_force_harmonic_flag(water_dft_fchk)**
- Extract with `force_harmonic=True` and without
- If the .fchk has anharmonic sections, the frequency values should differ. If not (DFT fchk may or may not have them), at minimum assert both calls succeed and return same shape.
- This tests the force_harmonic code path.

**Test 9: test_coordinates_bohr_to_angstrom(water_dft_fchk)**
