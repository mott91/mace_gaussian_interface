Create the file `.github/workflows/ci.yml` with the following content exactly:

```yaml
name: CI

on:
  push:

jobs:
  lint:
    name: Lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.10"

      - name: Install ruff
        run: pip install "ruff==0.15.1"

      - name: Check code formatting
        run: ruff format --check mace_gaussian/ tests/

      - name: Lint code
        run: ruff check mace_gaussian/ tests/

  test:
    name: Test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.10"
          cache: "pip"

      - name: Install package without heavy deps
        run: pip install -e . --no-deps

      - name: Install test dependencies
        run: pip install "pytest>=7.0.0" "pytest-cov>=4.0" "numpy>=1.20.0" "pyzmq>=22.0.0" "ase>=3.22.0"

      - name: Run unit tests
        run: |
          pytest tests/ \
            -m "not gpu and not gaussian and not slow" \
            --cov=mace_gaussian \
            --cov-report=term-missing
```

Key decisions baked into this file (all per locked decisions or Claude's discretion):
- `on: push` with NO branches filter = runs on every push to any branch (locked decision)
- `python-version: "3.10"` = matches mace4ir_v2 production environment (Claude's discretion)
- `cache: "pip"` = caches pip downloads to speed up CI (Claude's discretion: yes, cache)
- `pip install -e . --no-deps` = installs mace_gaussian package without pulling dgl/espaloma
  (avoids Pitfall 1: dgl==2.2.1 has only Windows wheels, uv sync fails on ubuntu-latest)
- Separate `pip install` for pytest/numpy/ase/pyzmq = explicit lightweight deps only
  (NOT mace_ML_pkg or mace_dipole_pkg — locked decision: do not install in CI)
- `ruff==0.15.1` = pinned to version in uv.lock for reproducibility
- `-m "not gpu and not gaussian and not slow"` = excludes tests requiring GPU/Gaussian (locked)
- `--cov=mace_gaussian` = reports coverage for the package (locked: coverage is informational)
- `--cov-report=term-missing` = terminal output with uncovered lines (Claude's discretion)
- NO `--cov-fail-under` = coverage is informational only (locked decision)
- lint and test jobs run in PARALLEL (independent, no `needs:` field) for faster CI

DO NOT use `uv sync --locked` — this fails on ubuntu-latest due to dgl Windows-only wheels.
DO NOT add `needs: lint` to the test job — parallel is fine, faster CI.
DO NOT add coverage upload to external service — terminal only (locked decision).
