**PTH123 — open() → Path.open() (~24 occurrences across ~8 files):**

in each file. Key files: analyze_spectra.py, analysis_workflow.py, utils/results.py,
workflow.py, dft_baseline.py, gaussian/io.py, html_report_generator.py.

**PTH110 — os.path.exists() → Path.exists() (~10 occurrences):**
Replace `os.path.exists(x)` with `Path(x).exists()` or `x.exists()` if x is already a Path.
Key files: workflow.py, utils/results.py, dft_baseline.py.

**PTH100 — os.path.abspath() → Path.resolve() (~6 occurrences):**
Replace `os.path.abspath(x)` with `Path(x).resolve()`. Return value is a Path object
(not string), so wrap in `str()` at call sites that need a string. Key file: gaussian/io.py,
workflow.py.

**PTH107 — os.remove() → Path.unlink() (2 occurrences in zmq_server.py):**
Replace `os.remove(path)` with `Path(path).unlink()` or `path.unlink()`.

**SIM108 — ternary expression (4 occurrences in analyze_spectra.py):**
Convert if/else blocks to ternary where ruff suggests. Pattern:

      x = a

      x = b
Becomes: x = a if condition else b

**SIM105 — contextlib.suppress (1 in zmq_server.py):**

**SIM117 — nested with (1 in gm_helper.py):**
Merge nested `with` statements into a single `with a, b:` form.

**SIM102 — nested if (1 occurrence):**

**SIM118 — key in dict.keys() (1 occurrence):**

**B904 — raise from err (3 in gaussian/fchk.py):**
