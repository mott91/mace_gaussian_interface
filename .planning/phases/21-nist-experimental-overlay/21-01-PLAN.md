```python
@dataclass
class ExperimentalSpectrum:
    wavenumbers: np.ndarray   # cm-1, sorted ascending
    absorbance: np.ndarray    # normalized to [0, 1]
    source: str               # e.g., "NIST WebBook"
    molecule_name: str
    cas_number: str
```

3. Implement `fetch_experimental_spectrum(molecule_name: str, cache_dir: Path) -> ExperimentalSpectrum | None`:
   - Cache path: `cache_dir / "experimental" / "nist_ir.jdx"` (per D-05)
   - If cache_path exists, parse it with `jcamp.jcamp_readfile()` and return (per D-06)
   - Otherwise, search NIST: `nist.run_search(molecule_name, 'name')`
   - If `search.success is False` or `search.num_compounds == 0`, log warning and return None
   - Take `search.compounds[0]`, call `compound.get_ir_spectra()`
   - If `compound.ir_specs` is empty, log warning and return None
   - Iterate `compound.ir_specs`, for each: write JDX text to a temp file, parse with `jcamp.jcamp_readfile(tmp_path)`, check `data.get('state', '').lower()` contains `'gas'` (per D-03). Skip non-gas-phase spectra.
   - For matching gas-phase spectrum:
     - Check `yunits`: if `'TRANSMITTANCE'` in yunits.upper(), convert: if `np.max(y) > 2` (percent), `y = np.clip(y, 0.01, 100); y = 2.0 - np.log10(y)`; else `y = np.clip(y, 1e-6, 1.0); y = -np.log10(y)`
     - Sort by wavenumber ascending: `sort_idx = np.argsort(x); x = x[sort_idx]; y = y[sort_idx]`
     - Normalize to [0, 1]: `y = y / np.max(y)` if max > 0 (per D-08)
   - Save the raw JDX text to `cache_path` (create parent dirs with `mkdir(parents=True, exist_ok=True)`)
   - Return `ExperimentalSpectrum(wavenumbers=x, absorbance=y, source="NIST WebBook", molecule_name=compound.name, cas_number=compound.ID)`
   - If no gas-phase spectrum found after iterating all, return None
   - **Critical: wrap entire function body in try/except Exception, log error, return None (per D-04 -- never blocks analysis)**

4. Add a helper `_parse_jdx_file(jdx_path: Path) -> ExperimentalSpectrum | None` for loading from cache:
   - Uses `jcamp.jcamp_readfile(str(jdx_path))`
   - Applies same yunits conversion and normalization as above
   - Returns ExperimentalSpectrum or None on parse failure
