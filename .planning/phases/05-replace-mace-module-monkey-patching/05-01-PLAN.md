  <action>
Create `calculators/mace_loader.py` containing:

1. **`_ensure_dipole_importable()`** -- Adds `mace_dipole_pkg/` to `sys.path` lazily on first call. Use `_DIPOLE_PKG_DIR = str(Path(__file__).resolve().parent.parent / "mace_dipole_pkg")`. Check `if _DIPOLE_PKG_DIR not in sys.path` before inserting.

2. **`_DipoleModelUnpickler(pickle.Unpickler)`** -- Override `find_class(self, module, name)`. If `module == "mace.modules.models"`, call `_ensure_dipole_importable()`, import `mace_dipole_core.modules.models`, and return `getattr(dipole_models, name)` if found. Otherwise call `super().find_class(module, name)`.

3. **`_DipolePickleModule`** -- Class with `Unpickler = _DipoleModelUnpickler` attribute and `__getattr__` delegating to stdlib `pickle`. This is the drop-in `pickle_module` for `torch.load`.

4. **`load_dipole_calculator(model_path, device, model_type, default_dtype)`** -- Public function. Calls `_ensure_dipole_importable()`, imports `MACECalculator_dipole` from `mace_dipole_core.calculators.mace`, and `mace_dipole_core.calculators.mace` as `dipole_calc_module`. Temporarily patches `dipole_calc_module.torch.load` with a wrapper that injects `pickle_module=_DipolePickleModule()` and `weights_only=False`, constructs the calculator, then restores the original in a `finally` block. Returns the calculator instance.

5. **`MACEDipoleCalculator`** -- Move from `mace_calculators.py`. Identical interface (`__init__(model_path, device)`, `calculate_dipole(atoms, **kwargs)`). Replace internal `load_dipole_mace_calculator()` call with `load_dipole_calculator()`. Remove the `finally: cleanup_mace_modules()` block entirely. Keep all dipole format handling (tuple extraction, tensor conversion, shape normalization).

Use the exact code from the RESEARCH.md "Complete Safe Loader Module" section as the starting point, adapting MACEDipoleCalculator from `mace_calculators.py` lines 42-105.

Add module docstring explaining the pickle_module approach and why sys.modules manipulation is not needed.

Use `from __future__ import annotations` for modern type hints. Use logging via `logging.getLogger(__name__)`.
