    - Only include pairs where `len(dft_freqs) == len(ml_freqs) > 0`.
    - Also count atoms per molecule: read optimized.xyz from `comparison_results/{mol}/geometry_opt/optimized.xyz` using `ase.io.read` and count atoms. If not available, try to count from XYZ file referenced in batch manifest. Store as `n_atoms`.
