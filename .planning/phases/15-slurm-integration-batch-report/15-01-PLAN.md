<objective>
Implement SLURM DFT offloading so that `mace-gaussian batch molecules.txt --dft-on-cluster user@host` submits DFT baseline jobs to a SLURM cluster via SSH, polls for completion with hourly status updates, retrieves results via SCP, and converts .chk to .fchk locally as fallback.

Purpose: Enables running DFT baselines on HPC clusters instead of the local machine, which is required for the ~25-molecule benchmark campaign (Phase 16). The user runs one command and walks away.
Output: `mace_gaussian/slurm.py`, `templates/slurm_dft.sh`, updated `batch.py` and `cli.py`
</objective>

    - `_ssh_run(host: str, command: str, timeout: int = 60) -> subprocess.CompletedProcess` — runs `subprocess.run(["ssh", "-o", "ConnectTimeout=30", "-o", "BatchMode=yes", "-o", "StrictHostKeyChecking=accept-new", host, command], capture_output=True, text=True, timeout=timeout)`. Per D-04, passwordless SSH assumed.
    - `_scp_to(host: str, local: str, remote: str, timeout: int = 120) -> subprocess.CompletedProcess` — runs `subprocess.run(["scp", "-o", "ConnectTimeout=30", "-o", "BatchMode=yes", local, f"{host}:{remote}"], ...)`. Per D-05, SCP for transfer.
    - `_scp_from(host: str, remote: str, local: str, timeout: int = 120) -> subprocess.CompletedProcess` — same pattern, reversed direction.
    - `_ssh_with_backoff(host: str, command: str, max_retries: int = 5) -> subprocess.CompletedProcess` — exponential backoff wrapper per D-18. Wait times: `min(2 ** attempt * 30, 600)` seconds. Retry on SSH connection error (returncode 255) or TimeoutExpired. After max_retries, raise `ConnectionError`.

    **Core functions:**
    - `submit_dft_jobs(molecules: list[dict], host: str, template_path: Path, results_dir: str = "comparison_results") -> dict[str, str]` — For each molecule dict (keys: `name`, `gjf_path`):
      1. Read template from `template_path`, fill placeholders `{molecule}`, `{remote_dir}` (= `~/mace_gaussian_dft/{name}` per D-03), `{gjf_filename}`, `{chk_filename}` (= `{name}_freq_anharm.chk`), `{fchk_filename}` (= `{name}_freq_anharm.fchk`)
      2. `_ssh_run(host, f"mkdir -p ~/mace_gaussian_dft/{name}")` to create remote dir per D-03
      3. SCP the .gjf file to `{host}:~/mace_gaussian_dft/{name}/`
      4. SCP the filled SLURM script to `{host}:~/mace_gaussian_dft/{name}/slurm_dft.sh`
      5. `_ssh_run(host, f"sbatch ~/mace_gaussian_dft/{name}/slurm_dft.sh")` — extract job ID from stdout `"Submitted batch job NNNNN"` by splitting on whitespace and taking last token
      6. Per D-02, submit ALL jobs upfront before returning
      Returns `{molecule_name: job_id}` dict.

    - `poll_jobs(host: str, job_ids: dict[str, str], poll_interval: int = 3600) -> dict[str, str]` — Blocking poll loop per D-07:
      1. Build sacct command: `sacct -j {comma_joined_ids} --format=JobID,State,ExitCode --noheader --parsable2`
      2. Use `_ssh_with_backoff` to run sacct
      3. Parse output: split each line on `|`, take `parts[0].split(".")[0]` as job_id (strip step suffix like ".batch"), `parts[1]` as state. Keep first entry per job_id (main job, not steps).
      4. Terminal states: `COMPLETED`, `FAILED`, `TIMEOUT`, `CANCELLED`, `NODE_FAIL`, `OUT_OF_MEMORY`, `PREEMPTED`
      5. If all jobs in terminal state, return `{molecule_name: state}` dict
      6. Otherwise print status line: `"SLURM status: {n_complete} completed, {n_running} running, {n_pending} pending, {n_failed} failed"` and sleep in 60-second increments (for Ctrl-C interruptibility, per pitfall 7) until `poll_interval` seconds total
      7. If sacct returns empty for a known job_id, treat as PENDING (per pitfall 2 — accounting lag)
      8. Per D-06, use SSH + sacct for polling

    - `retrieve_results(host: str, molecules: list[str], results_dir: str = "comparison_results") -> dict[str, bool]` — Per D-08, D-09:

For each molecule, SCP specific files by name (per pitfall 3, no globs): `{host}:~/mace_gaussian_dft/{name}/{name}_freq_anharm.log`, `{host}:~/mace_gaussian_dft/{name}/{name}_freq_anharm.chk`, and `{host}:~/mace_gaussian_dft/{name}/{name}_freq_anharm.fchk` (if exists on cluster, since template includes formchk per HPC-02)
      2. Place files in `{results_dir}/{molecule}/b3lyp_6-31Gdp/` (per D-09, existing directory structure)
      3. If .fchk was not retrieved (formchk failed on cluster), convert locally: `from .gaussian.fchk import convert_chk_to_fchk; convert_chk_to_fchk(chk_path)`
      4. Parse the .log file to extract results: `from .gaussian.parser import parse_gaussian_log`
      5. Save results.json using the same schema as local DFT runs
      6. Return `{molecule_name: success_bool}`

    ```python
    # SLURM DFT offload: submit all, poll, retrieve (per D-02, D-07)
    if dft_on_cluster and not skip_dft_baseline:
        from pathlib import Path as _P
        from .slurm import submit_dft_jobs, poll_jobs, retrieve_results
        from .gaussian.io import ase_to_gjf

        # Collect molecules needing DFT
        need_dft = []
        for mol_name, mol_data in manifest["molecules"].items():
            if mol_data.get("dft_baseline") != STATUS_COMPLETE:
                # Check if already has a SLURM job submitted
                slurm_info = mol_data.get("slurm", {})
                if slurm_info.get("status") not in TERMINAL_STATES_SET:
                    need_dft.append(mol_name)

        if need_dft:
            # Resolve template path
            template = _P(slurm_template) if slurm_template else _P(__file__).parent.parent / "templates" / "slurm_dft.sh"

            # Generate .gjf files for molecules needing DFT
            molecules_for_slurm = []
            for mol_name in need_dft:
                mol_data = manifest["molecules"][mol_name]
                xyz_path = mol_data["xyz_path"]
                opt_geom = results_mgr.get_optimized_geometry_path(mol_name)
                if opt_geom.exists():
                    atoms = read(str(opt_geom))
                    gjf_path = _P(output_dir) / mol_name / "b3lyp_6-31Gdp" / f"{mol_name}_freq_anharm.gjf"
                    gjf_path.parent.mkdir(parents=True, exist_ok=True)
                    ase_to_gjf(atoms, str(gjf_path), molecule_name=mol_name)
                    molecules_for_slurm.append({"name": mol_name, "gjf_path": str(gjf_path)})

            if molecules_for_slurm:
                click.echo(f"\nSubmitting {len(molecules_for_slurm)} DFT job(s) to {dft_on_cluster}...")
                job_ids = submit_dft_jobs(molecules_for_slurm, dft_on_cluster, template, output_dir)

                # Record job IDs in manifest (per D-17)
                for mol_name, job_id in job_ids.items():
                    manifest["molecules"][mol_name]["slurm"] = {
                        "job_id": job_id,
                        "host": dft_on_cluster,
                        "remote_dir": f"~/mace_gaussian_dft/{mol_name}",
                        "status": "SUBMITTED",
                    }
                save_manifest(manifest, manifest_path)

                # Poll until all complete (per D-07, D-16)
                click.echo("Polling SLURM jobs (hourly updates)...")
                final_states = poll_jobs(dft_on_cluster, job_ids)

                # Update manifest with final states
                completed_mols = []
                for mol_name, state in final_states.items():
                    manifest["molecules"][mol_name]["slurm"]["status"] = state
                    if state == "COMPLETED":
                        completed_mols.append(mol_name)
                    else:
                        # Per D-17: mark dft_failed, continue
                        manifest["molecules"][mol_name]["dft_baseline"] = "dft_failed"
                        click.echo(f"  SLURM job for {mol_name} ended with state: {state}")
                save_manifest(manifest, manifest_path)

                # Retrieve results for completed molecules (per D-08)
                if completed_mols:
                    click.echo(f"Retrieving results for {len(completed_mols)} molecule(s)...")
                    retrieve_results(dft_on_cluster, completed_mols, output_dir)
                    for mol_name in completed_mols:
                        manifest["molecules"][mol_name]["dft_baseline"] = STATUS_COMPLETE
                    save_manifest(manifest, manifest_path)
    ```
