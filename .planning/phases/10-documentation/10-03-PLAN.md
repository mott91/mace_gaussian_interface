    # Computational Methods

    ## 1. Computational Framework Overview

    Describe the end-to-end pipeline:
    - Geometry optimization with MACE ML potential, followed by vibrational frequency calculation
    - Gaussian 16 used for frequency calculation infrastructure; ML models injected via external interface
    - Two types of calculation: anharmonic (VPT2, primary) and harmonic (fundamentals only)
    - Four ML model combinations compared: two energy models × two dipole models
    - Reference DFT calculations (B3LYP/6-31G(d,p)) for validation

    ## 2. MACE Potential Energy Models

    Describe:
    - MACE (Multi-ACE) architecture: E(3)-equivariant graph neural network with higher-order
      equivariant message passing. Key property: invariance to rotation, reflection, and translation
      ensures physical consistency of energy predictions.
    - MACE-MP-0: pre-trained on the Materials Project database (~150,000 diverse inorganic and
      organic structures). Selected for broad chemical coverage.
    - MACE-OMOL-0: pre-trained on the Open Molecules 2025 (OMol25) dataset. Focused on organic
      molecules; better suited for drug-like and hydrogen-bonded systems.
    - Both models were used without fine-tuning on IR-specific data. Comparison across models
      allows assessment of training data distribution effects on spectral predictions.
    - Geometry optimization performed with MACE-OMOL-0 (default) using ASE optimizer.

    ## 3. Dipole Derivative Calculation

    Describe:
    - Two dipole model backends compared: Espaloma and MACE4IR.
    - Espaloma: ML partial charge model. Dipole moments derived from predicted partial charges
      on each atom. Fast and general-purpose.
    - MACE4IR: custom fork of MACE trained specifically for dipole moment prediction,
      covering 78 elements. Provides more direct prediction of molecular dipole surfaces.
    - Dipole derivatives (required for IR intensities) computed via numerical finite differences:
      each atom displaced ±δ in x, y, z (6N evaluations per molecule, N = number of atoms).
    - The four ML combinations tested (mace_mp/mace_omol × espaloma/mace_ml) allow systematic
      assessment of energy model vs. dipole model contributions to spectral accuracy.

    ## 4. ZMQ Injection Mechanism

    Describe the novel software bridge — this is the key methodological contribution:
    - Gaussian's `External=` keyword enables injection of user-calculated energy, gradient,
      and dipole data into the Gaussian SCF/frequency framework.
    - A Python process pre-loads the ML model and binds a ZMQ IPC socket. Gaussian launches
      a helper script (`gm_helper.py`) as a subprocess at each step of the VPT2 derivative
      evaluation.
    - The helper script connects to the ZMQ socket, transmits the current geometry (from
      Gaussian's input file) to the main Python process, and waits for the response.
    - The main process evaluates the ML model, computes energy, forces, dipole moment,
      and dipole derivatives, then writes them to Gaussian's expected external output format.
    - Gaussian reads this data and continues the anharmonic calculation, treating ML-derived
      derivatives as if they came from a DFT electronic structure calculation.
    - This approach enables VPT2 anharmonic treatment with ML-derived dipole surfaces —
      a combination not natively available from ML potentials.
    - IPC (Unix domain socket) was used for inter-process communication to minimize latency
      for the many Gaussian↔Python round-trips required during anharmonic derivative evaluation.

    ## 5. VPT2 Anharmonic Treatment

    Describe:
    - Second-order vibrational perturbation theory (VPT2) was applied using Gaussian 16's
      implementation.
    - VPT2 corrects harmonic frequencies using cubic and quartic terms from a numerical
      differentiation of the potential energy surface. This produces anharmonic fundamental
      frequencies, overtone bands (2ν_i), and combination bands (ν_i + ν_j).
    - Anharmonic treatment was chosen because experimental IR spectra of small organic molecules
      exhibit prominent overtone and combination features that harmonic calculations cannot reproduce.
    - The B3LYP/6-31G(d,p) level of theory was used for all DFT reference calculations,
      consistent with common practice for mid-sized organic molecules.
    - ML-based anharmonic calculations used the same VPT2 framework in Gaussian, with
      ML-derived energy, forces, and dipole derivatives substituted for DFT quantities.

    ## 6. Mode Matching

    Describe:
    - Vibrational mode ordering can differ between DFT and ML calculations, particularly
      when near-degenerate modes are present.
    - Mode matching was performed using eigenvector dot product overlap: for each pair of
      DFT mode i and ML mode j, the overlap O_ij = |q_i · q_j| was computed, where q
      are mass-weighted normal-mode eigenvectors.
    - Hungarian algorithm assignment was applied to the overlap matrix to find the
      one-to-one mode correspondence that maximizes total overlap.
    - This approach assigns modes by physical similarity (shape of atomic motion) rather
      than frequency ordering, producing more robust comparisons when mode ordering differs.
    - Normal modes were obtained from formatted checkpoint files (`.fchk`) produced by
      Gaussian's `formchk` utility.

    ## 7. Analysis and Validation

    Describe:
    - Calculated frequencies were compared against DFT reference values using three metrics:
      mean absolute error (MAE, cm⁻¹), root mean square error (RMSE, cm⁻¹), and
      coefficient of determination (R²).
    - Regression plots of ML vs. DFT frequencies were generated for visual assessment of
      systematic offsets or frequency-dependent biases.
    - Simulated IR spectra were generated by convolving discrete frequency stick spectra
      with Gaussian kernels (FWHM 8.0 cm⁻¹) to represent instrumental broadening.
    - All four ML combinations (mace_mp/mace_omol × espaloma/mace_ml) were evaluated
      independently to isolate the effect of each model choice.
    - The reference DFT method (B3LYP/6-31G(d,p)) was treated as ground truth for
      frequency comparison; absolute accuracy vs. experiment was not the primary objective.
