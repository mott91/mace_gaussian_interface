# Phase 13.4: Frequency Range Coverage Analysis - Context

**Gathered:** 2026-03-15
**Status:** Ready for planning

<domain>
## Phase Boundary

Build a diagnostic that splits the IR spectrum into chemically meaningful frequency regions, computes per-region ML vs DFT error metrics, and cross-references across multiple molecules to identify systematic ML training set gaps. Produces heatmap, bar chart, and HTML report for thesis.

</domain>

<decisions>
## Implementation Decisions

### Region definitions
- 7 chemically meaningful regions (not standard 4, not arbitrary bins):
  - 400-700 cm-1: Skeletal bending, torsions, heavy-atom stretches
  - 700-1000 cm-1: C-X stretches, aromatic C-H out-of-plane bends
  - 1000-1300 cm-1: C-O / C-C stretches, CH bending
  - 1300-1500 cm-1: CH2/CH3 deformations, ring stretches
  - 1500-1800 cm-1: C=C, C=O, C=N double bond stretches
  - 1800-2800 cm-1: Silent zone / triple bonds (deliberately wide, usually sparse)
  - 2800-4000 cm-1: C-H, N-H, O-H stretches
- Rationale: granular enough to spot "MACE struggles in region X" patterns, but each bin has a physical story for the thesis

### Error metrics
- Compute all four per region:
  - RMSE (cm-1) — primary metric, consistent with regression plots
  - MAE (cm-1) — paired with RMSE to distinguish uniform vs outlier-driven error
  - Mean % error — normalizes across frequency scale (20 cm-1 means different things at 500 vs 3000)
  - Mode count — essential context, can't trust metrics from 1 mode

### Cross-molecule aggregation
- Both heatmap AND bar chart:
  - Heatmap: molecules x regions matrix, one per calculator combo, colored by RMSE
  - Bar chart: mean RMSE by region across all molecules, with error bars (std dev)
- Empty cells (no modes in region for a molecule): gray cell with "--" text annotation
- No extra flagging or thresholds — color scale communicates severity on its own

### Output & integration
- Standalone script: `run_coverage_analysis.py` taking molecule names as arguments
- Produces standalone HTML report (self-contained, embedded plots, like per-molecule reports)
- Also saves PNG plots + JSON with raw metrics in `coverage_analysis/` directory
- Uses harmonic analysis results only (analysis_results_harmonic/) — Hungarian mode matching is most reliable there

### Claude's Discretion
- Colormap choice for heatmap
- Bar chart styling details
- HTML report layout and sections
- JSON schema for raw metrics output
- How to discover available calculator combos from existing results

</decisions>

<specifics>
## Specific Ideas

- Each region should have a physical story explainable in a thesis chapter
- The silent zone (1800-2800) is deliberately wide because it's usually empty
- RMSE >> MAE in a region indicates outlier-driven error (important diagnostic insight)

</specifics>

- `ComparisonWorkflow` / `HarmonicComparisonWorkflow` in `analysis_workflow.py`: existing pattern for loading results and orchestrating analysis

### Integration Points
- Reads from `analysis_results_harmonic/` (per-molecule harmonic analysis must be run first)
- Reads matched frequency pairs from per-molecule comparison data
- Outputs to new `coverage_analysis/` directory
