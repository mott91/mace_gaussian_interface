**Researched:** 2026-03-15
**Domain:** IR spectral analysis, cross-molecule diagnostic, matplotlib/seaborn visualization
**Confidence:** HIGH

## Summary

This phase builds a standalone diagnostic tool that splits the IR spectrum into 7 chemically meaningful frequency regions, computes per-region ML vs DFT error metrics, and aggregates results across multiple molecules to identify systematic ML training set gaps. The output is a heatmap (molecules x regions), a bar chart (mean RMSE by region with error bars), and a standalone HTML report with embedded plots.

The implementation is straightforward because all building blocks exist: the per-molecule harmonic comparison CSVs already contain matched DFT and ML frequency pairs (from Hungarian mode matching in Phase 13.3), the HTML report generator provides a proven pattern for self-contained reports, and the plotting conventions (seaborn colorblind palette, DPI=300, PNG) are established.

**Primary recommendation:** Create a single new module `mace_gaussian/analysis/coverage_analysis.py` with a thin entry-point script `run_coverage_analysis.py`, reusing pandas for data aggregation and matplotlib/seaborn for visualization. Read directly from the existing `analysis_results_harmonic/{molecule}/data/comparison_*.csv` files.

## User Constraints (from CONTEXT.md)

### Locked Decisions
- 7 chemically meaningful regions (not standard 4, not arbitrary bins):
  - 400-700 cm-1: Skeletal bending, torsions, heavy-atom stretches
  - 700-1000 cm-1: C-X stretches, aromatic C-H out-of-plane bends
  - 1000-1300 cm-1: C-O / C-C stretches, CH bending
  - 1300-1500 cm-1: CH2/CH3 deformations, ring stretches
  - 1500-1800 cm-1: C=C, C=O, C=N double bond stretches
  - 1800-2800 cm-1: Silent zone / triple bonds (deliberately wide, usually sparse)
  - 2800-4000 cm-1: C-H, N-H, O-H stretches
- Compute all four metrics per region: RMSE (cm-1), MAE (cm-1), Mean % error, Mode count
- Both heatmap AND bar chart:
  - Heatmap: molecules x regions matrix, one per calculator combo, colored by RMSE
  - Bar chart: mean RMSE by region across all molecules, with error bars (std dev)
- Empty cells (no modes in region for a molecule): gray cell with "--" text annotation
- No extra flagging or thresholds -- color scale communicates severity on its own
- Standalone script: `run_coverage_analysis.py` taking molecule names as arguments
- Produces standalone HTML report (self-contained, embedded plots)
- Also saves PNG plots + JSON with raw metrics in `coverage_analysis/` directory
- Uses harmonic analysis results only (analysis_results_harmonic/)

### Pattern 1: Data Flow
**What:** Read existing per-molecule CSVs, bin frequencies into regions, compute per-region metrics, aggregate across molecules.
**When to use:** This is the only data flow pattern needed.
**Key insight:** The comparison CSV columns are: `DFT_Frequency_cm`, `ML_Frequency_cm`, `Freq_Difference_cm`, `Percent_Error`, `Mode_Overlap`, `DFT_Intensity_km_mol`, `ML_Intensity_km_mol`, `Intensity_Difference`. The `DFT_Frequency_cm` column is the natural binning key since DFT is the reference.

```python
# Binning approach using pd.cut
REGIONS = [
    (400, 700, "400-700\nSkeletal"),
    (700, 1000, "700-1000\nC-X, C-H oop"),
    (1000, 1300, "1000-1300\nC-O/C-C, CH bend"),
    (1300, 1500, "1300-1500\nCH2/CH3 def"),
    (1500, 1800, "1500-1800\nC=C, C=O"),
    (1800, 2800, "1800-2800\nSilent zone"),
    (2800, 4000, "2800-4000\nX-H stretch"),
]

bins = [r[0] for r in REGIONS] + [REGIONS[-1][1]]
labels = [r[2] for r in REGIONS]
df["region"] = pd.cut(df["DFT_Frequency_cm"], bins=bins, labels=labels, right=False)
```

### Anti-Patterns to Avoid
- **Re-running mode matching:** The CSVs already have matched pairs from Hungarian matching. Do NOT re-match modes -- just read the CSVs.
- **Filtering by mode overlap threshold:** The CONTEXT.md says no extra flagging or thresholds. Include all matched modes regardless of overlap quality.
- **Using DFT_Frequency_cm values below 400 or above 4000:** Some CSV rows include very low frequencies (aspirin has 31 cm-1). These fall outside all 7 regions and should be silently dropped by `pd.cut`.

## Common Pitfalls

### Pitfall 1: Empty Regions Causing NaN Metrics
**What goes wrong:** Water has only 3 modes (all in 1500-4000 range). Most regions will be empty, causing division by zero in RMSE/MAE.
**Why it happens:** Small molecules have few modes; the silent zone (1800-2800) is often empty for any molecule.
**How to avoid:** Use `np.nan` for empty regions. In the heatmap, use seaborn's `mask` parameter to gray out NaN cells, and `annot` with a custom formatter that shows "--" for masked cells.
**Warning signs:** Warnings about mean of empty slice.

### Pitfall 2: Frequencies Outside 400-4000 Range
**What goes wrong:** Some CSVs contain very low frequencies (aspirin has 31 cm-1) or negative frequencies from imaginary modes.
**Why it happens:** Hungarian matching pairs all modes including very low torsional modes.
**How to avoid:** `pd.cut` with the defined bins will assign `NaN` to out-of-range frequencies, which `groupby` will silently exclude. This is the correct behavior.

### Pitfall 3: Inconsistent Calculator Combos Across Molecules
**What goes wrong:** Not all molecules have all calculator combos (e.g., mace_anicc only supports CHNO, so non-CHNO molecules won't have it).
**Why it happens:** Element coverage varies by energy calculator.
**How to avoid:** Discover combos per molecule, build a union set for the heatmap axes, and use NaN/masking for missing molecule-combo pairs.

### Pitfall 4: Percent Error Near Zero Frequency
**What goes wrong:** Mean % error explodes when DFT frequency is near zero (e.g., aspirin's 31 cm-1 mode with -162% error).
**Why it happens:** Division by small denominator.
**How to avoid:** This is handled naturally since out-of-range frequencies are dropped by `pd.cut`. But if any frequencies between 400-700 are very small, the % error will still be large. This is expected behavior -- it's a real diagnostic signal.

### Pitfall 5: Heatmap Axis Labels Too Long
**What goes wrong:** Calculator combo names like "mace_anicc_mace_ml" and region labels with descriptions overflow.
**Why it happens:** Many combos and regions make axis labels dense.
**How to avoid:** Use shorter region labels on the axis (just "400-700" etc.) with a legend/caption mapping to physical descriptions. Or use wrapped two-line labels with `\n`.

## Code Examples

### Per-Region Metric Computation
```python
import numpy as np
import pandas as pd

def compute_region_metrics(df: pd.DataFrame) -> dict:
    """Compute RMSE, MAE, Mean % Error, and mode count for a frequency region."""
    if df.empty:
        return {"rmse": np.nan, "mae": np.nan, "mean_pct_error": np.nan, "mode_count": 0}

    diff = df["ML_Frequency_cm"].values - df["DFT_Frequency_cm"].values
    pct_errors = df["Percent_Error"].values  # Already computed in CSV

    return {
        "rmse": float(np.sqrt(np.mean(diff**2))),
        "mae": float(np.mean(np.abs(diff))),
        "mean_pct_error": float(np.mean(np.abs(pct_errors))),
        "mode_count": len(df),
    }
```

### Heatmap with Masked Empty Cells
```python
import seaborn as sns
import matplotlib.pyplot as plt
import numpy as np

def plot_coverage_heatmap(
    data: pd.DataFrame,  # molecules (rows) x regions (cols), values = RMSE
    calc_combo: str,
    save_path: str,
):
    fig, ax = plt.subplots(figsize=(12, max(4, len(data) * 0.6 + 2)))

    mask = data.isna()

    # Use sequential colormap -- low RMSE = good (light), high = bad (dark)
    sns.heatmap(
        data,
        annot=True,
        fmt=".1f",
        mask=mask,
        cmap="YlOrRd",  # Yellow (good) -> Orange -> Red (bad)
        cbar_kws={"label": "RMSE (cm$^{-1}$)"},
        linewidths=0.5,
        linecolor="white",
        ax=ax,
    )

    # Annotate masked cells with "--"
    for i in range(data.shape[0]):
        for j in range(data.shape[1]):
            if mask.iloc[i, j]:
                ax.text(j + 0.5, i + 0.5, "--", ha="center", va="center",
                        color="gray", fontsize=9)

    ax.set_title(f"Frequency Region Coverage: {calc_combo}", fontsize=13, fontweight="bold")
    ax.set_xlabel("Frequency Region (cm$^{-1}$)")
    ax.set_ylabel("Molecule")

    plt.tight_layout()
    fig.savefig(save_path, dpi=300, bbox_inches="tight")
    plt.close(fig)
```

### Bar Chart with Error Bars
```python
def plot_region_barchart(
    region_means: dict[str, float],   # region_label -> mean RMSE
    region_stds: dict[str, float],    # region_label -> std RMSE
    region_counts: dict[str, int],    # region_label -> total mode count
    calc_combo: str,
    save_path: str,
):
    regions = list(region_means.keys())
    means = [region_means[r] for r in regions]
    stds = [region_stds[r] for r in regions]
    counts = [region_counts[r] for r in regions]

    fig, ax = plt.subplots(figsize=(10, 5))

    colors = sns.color_palette("colorblind", len(regions))
    bars = ax.bar(range(len(regions)), means, yerr=stds, capsize=4,
                  color=colors, edgecolor="white", linewidth=0.5)

    # Annotate with mode counts
    for i, (bar, count) in enumerate(zip(bars, counts)):
        ax.text(bar.get_x() + bar.get_width() / 2, bar.get_height() + stds[i] + 1,
                f"n={count}", ha="center", va="bottom", fontsize=8, color="gray")

    ax.set_xticks(range(len(regions)))
    ax.set_xticklabels(regions, rotation=45, ha="right", fontsize=8)
    ax.set_ylabel("RMSE (cm$^{-1}$)")
    ax.set_title(f"Mean RMSE by Frequency Region: {calc_combo}", fontsize=13, fontweight="bold")

    plt.tight_layout()
    fig.savefig(save_path, dpi=300, bbox_inches="tight")
    plt.close(fig)
```

## Open Questions

1. **Heatmap colormap choice**
   - Recommendation: `YlOrRd` (yellow-orange-red sequential). Low RMSE = yellow (good), high = red (bad). This is intuitive and colorblind-friendly. Alternative: `RdYlGn_r` (red-yellow-green reversed) but green-red has colorblind issues.

2. **How to handle molecules with only harmonic data but no analysis_results_harmonic**
   - What we know: Only molecules that have been through `run_analysis_harmonic.py` will have CSVs
   - Recommendation: Script should warn and skip molecules without harmonic results, not crash

3. **JSON schema for raw metrics**
   - Recommendation: Nest as `{calc_combo: {molecule: {region: {rmse, mae, mean_pct_error, mode_count}}}}`
   - This makes it easy to load for further analysis or thesis table generation
