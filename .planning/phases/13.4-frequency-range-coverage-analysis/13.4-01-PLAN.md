Create `mace_gaussian/analysis/coverage_analysis.py` with:

1. Module-level `FREQUENCY_REGIONS` list of 7 tuples: `(low, high, label, description)` per user decision:
   - (400, 700, "400-700", "Skeletal bending, torsions, heavy-atom stretches")
   - (700, 1000, "700-1000", "C-X stretches, aromatic C-H out-of-plane bends")
   - (1000, 1300, "1000-1300", "C-O/C-C stretches, CH bending")
   - (1300, 1500, "1300-1500", "CH2/CH3 deformations, ring stretches")
   - (1500, 1800, "1500-1800", "C=C, C=O, C=N double bond stretches")
   - (1800, 2800, "1800-2800", "Silent zone / triple bonds")
   - (2800, 4000, "2800-4000", "C-H, N-H, O-H stretches")

2. `CoverageAnalyzer` class with methods:
   - `__init__(self, molecules: list[str], results_base: Path = Path("analysis_results_harmonic"))` — stores molecule names and base path
   - `_bin_frequencies(self, df: pd.DataFrame) -> pd.DataFrame` — adds "region" column using `pd.cut` on `DFT_Frequency_cm` with bins from FREQUENCY_REGIONS; right=False
   - `_compute_region_metrics(self, df: pd.DataFrame) -> dict` — for a single-region DataFrame, returns `{"rmse": float, "mae": float, "mean_pct_error": float, "mode_count": int}`. Empty df returns NaN metrics with mode_count=0. Uses `np.abs` on Percent_Error column for mean_pct_error.
   - `_discover_calc_combos(self, molecule: str) -> list[str]` — globs `comparison_*.csv` in `results_base/{molecule}/data/`, returns combo names (strip "comparison_" prefix and ".csv" suffix)
   - `_load_molecule_data(self, molecule: str, calc_combo: str) -> pd.DataFrame` — reads CSV, bins frequencies, returns DataFrame with region column
   - `analyze(self) -> dict` — main method. For each molecule, discovers calc combos, loads data, computes per-region metrics. Returns nested dict: `{calc_combo: {molecule: {region_label: {rmse, mae, mean_pct_error, mode_count}}}}`
   - `build_heatmap_data(self, metrics: dict, calc_combo: str) -> pd.DataFrame` — builds molecules (rows) x regions (cols) DataFrame with RMSE values for heatmap. Missing molecule-combo -> NaN row.
   - `build_barchart_data(self, metrics: dict, calc_combo: str) -> tuple[dict, dict, dict]` — returns (region_means, region_stds, region_counts) across all molecules for a given calc_combo. NaN regions excluded from mean/std computation.

Create `tests/test_coverage_analysis.py` with fixtures using synthetic DataFrames (not real files) and tests for all behaviors listed above.

Write tests FIRST (RED), then implement (GREEN).
