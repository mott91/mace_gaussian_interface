# Phase 23: Anharmonic Pipeline & Report Overhaul - Context

**Gathered:** 2026-04-05
**Status:** Ready for planning

<domain>
## Phase Boundary

The anharmonic analysis pipeline produces a thesis-quality HTML report integrating all v1.2 features (Lorentzian spectra, experimental overlay, timing breakdown, degenerate-mode-aware mode matching) into a single cohesive document. The harmonic report is updated to share the same template and visual style. This phase does NOT include thesis figure generation (separate future phase), JCAMP-DX export, peak confidence scores, or conformer-aware spectra.

</domain>

<decisions>
## Implementation Decisions

### Report structure & narrative flow
- **D-01:** Executive summary first — the report opens with a 1-page summary showing the best-performing method, key findings, and speedup. Reader gets the punchline immediately before drilling into details.
- **D-02:** Per-molecule summary cards show: R² (frequency), R² (intensity), RMSE, speedup factor, best-performing method highlighted, experimental agreement score (when available). Auto-generated verdict like "mace_off+espaloma is closest to experiment".
- **D-03:** Report flow: executive summary → combined plots → per-method detail sections → summary table → footer.

### Harmonic/anharmonic report coherence
- **D-04:** Shared template, mode-aware. Same CSS, same layout, same executive summary format. Anharmonic report adds overtone/combination sections that harmonic report skips. Both reports feel like the same product, just different depth.
- **D-05:** Both reports are generated by the same `HTMLReportGenerator` class with a mode flag controlling which sections appear.

### Plot rendering
- **D-06:** Use Plotly.js for interactive plots in the HTML report. Zoomable, hoverable spectra. Plotly.js bundled in the HTML file (self-contained).
- **D-07:** Structured data export (JSON/CSV) saved alongside the report for future thesis figure generation. This phase does NOT generate print-ready matplotlib figures.
- **D-08:** Replace current matplotlib PNG + base64 embedding with Plotly div elements inline in HTML.

### Feature integration
- **D-09:** Timing breakdown, experimental overlay, and degenerate-mode info are all inline within each per-method comparison section. No separate bolt-on sections.
- **D-10:** Experimental trace (black dashed line, per Phase 21 convention) appears on every per-method spectrum plot — DFT + ML + experimental on the same interactive plot.
- **D-11:** Each per-method section contains: spectrum plot (with experimental overlay), regression plot, mode overlap heatmap, timing breakdown, degenerate mode notes. Everything about one method in one place.

### Claude's Discretion
- Plotly layout configuration (hover templates, axis formatting, subplot arrangement)
- Executive summary verdict generation logic (how to determine "best" method)
- Data export format details (JSON structure, CSV columns)
- How to handle molecules with no experimental data in the executive summary
- Plotly CDN vs bundled — as long as report is self-contained

### Folded Todos
- **Interactive HTML spectrum viewer with Plotly** — absorbed naturally since D-06 decides on Plotly for all report plots

</decisions>
