  <name>Task 1: Harden parser errors and fix optimization step tracking</name>
  <files>gaussian_parser.py, gm_main.py</files>
  <action>
**gaussian_parser.py changes:**

1. Add import at top: `from exceptions import GaussianParseError`

2. Modify `parse_harmonic_frequencies()`:
   - After the parsing loop, if `frequencies` is empty, raise `GaussianParseError` with message including the log file path and hint to check that the calculation completed normally with a frequency calculation.
   - This is always an error because ANY freq calculation log must have harmonic frequencies.

3. Modify `parse_anharmonic_frequencies()` to accept `strict: bool = False` parameter:
   - If `strict=True` and `frequencies` is empty after parsing, raise `GaussianParseError` with message indicating no Fundamental Bands section was found.
   - If `strict=False` (default), keep current behavior of returning empty list. This preserves backward compatibility since some valid logs lack anharmonic data (harmonic-only DFT runs).

4. Modify `parse_overtones()` to accept `strict: bool = False` parameter:
   - Same pattern: raise `GaussianParseError` when `strict=True` and result is empty.
   - Default `strict=False` keeps backward compat (some small molecules legitimately have no parsed overtones).

5. Modify `parse_combination_bands()` to accept `strict: bool = False` parameter:
   - Same pattern as overtones.

6. Do NOT modify `parse_final_energy()` or `parse_dipole_moment()` -- returning None is the correct contract for these.

**gm_main.py changes:**

1. Modify `geometry_optimisation(mol, fmax=0.000001)`:
   - After `opt.run(fmax=fmax, steps=10000)`, add: `num_steps = opt.get_number_of_steps()`
   - Print the step count: `print(f"Optimization steps: {num_steps}")`
   - Change return to: `return mol, num_steps`

2. Modify `run_geometry_optimization()` (the single caller, around line 833):
   - Change line `optimized_atoms = geometry_optimisation(atoms)` to `optimized_atoms, num_steps = geometry_optimisation(atoms)`
   - Change `num_steps=0,  # TODO: track this if needed` to `num_steps=num_steps,`

These are contained changes -- `geometry_optimisation` is only called in one place (`run_geometry_optimization`).
  </action>
