<task type="auto">
  <name>Task 1: Create exception hierarchy and validation module</name>
  <files>exceptions.py, validation.py</files>
  <action>
Create `exceptions.py` with a flat exception hierarchy:
- `MaceGaussianError(Exception)` - base exception for all MACE-Gaussian interface errors
- `PrerequisiteError(MaceGaussianError)` - a required external tool or file is missing
- `GaussianParseError(MaceGaussianError)` - failed to parse expected data from Gaussian output
- `InputValidationError(MaceGaussianError)` - input file or parameter failed validation
- `CUDANotAvailableWarning(UserWarning)` - CUDA requested but not available

Each class should have a docstring explaining when to use it.

Create `validation.py` with these pure functions (all using stdlib + existing deps only):

1. `check_gaussian_available() -> str` - uses `shutil.which("g16")`, returns path or raises `PrerequisiteError` with message including "module load gaussian" hint
2. `check_formchk_available() -> str` - uses `shutil.which("formchk")`, returns path or raises `PrerequisiteError`
3. `check_dipole_model(model_path: str) -> Path` - checks file exists, raises `PrerequisiteError` if not, with hint about MACE_DIPOLE_MODEL_PATH env var
4. `check_helper_script(script_path: str) -> Path` - checks file exists, raises `PrerequisiteError` if not
5. `validate_xyz_file(file_path: str) -> dict` - checks file exists, has .xyz suffix, is parseable by `ase.io.read()`, has reasonable atom count (warn >200 via logger, not error). Returns `{"path": str, "n_atoms": int, "symbols": list}`. Raises `InputValidationError` on failure.
6. `validate_all_prerequisites(check_gaussian: bool = True, check_formchk_tool: bool = True, dipole_model_path: str = None, helper_script_path: str = None) -> dict` - runs all checks, returns summary dict, raises on first failure
7. `detect_device() -> str` - uses `torch.cuda.is_available()`, logs GPU name on CUDA, logs warning on CPU fallback. Returns "cuda" or "cpu".
8. `collect_version_metadata() -> dict` - collects tool_version (from pyproject.toml via `importlib.metadata.version("mace-gaussian-interface")` with fallback to "0.2.0"), python_version, platform, mace_version, torch_version, cuda info, ase_version. All values must be native Python types (str, bool, int) for JSON serialization.

Use `logging.getLogger(__name__)` for the module logger. Follow existing codebase conventions (snake_case, type hints, numpy-style docstrings).

Add `validation` and `exceptions` to the `known-first-party` list in `pyproject.toml` under `[tool.ruff.lint.isort]`.
  </action>
