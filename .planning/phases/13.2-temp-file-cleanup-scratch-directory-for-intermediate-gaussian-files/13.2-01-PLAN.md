3. `list_stale_scratch_dirs(base_dir=".")` — same scan but returns `list[tuple[str, float]]` of (name, age_hours) without deleting.

Constants: `SCRATCH_ROOT = ".scratch"`, `STALE_THRESHOLD_SECONDS = 24 * 3600`.

Write tests in `tests/test_scratch.py` using `tmp_path` fixture. For stale dir tests, use `os.utime()` to backdate directory mtime. Test the BaseException path by raising `KeyboardInterrupt` inside the context.
