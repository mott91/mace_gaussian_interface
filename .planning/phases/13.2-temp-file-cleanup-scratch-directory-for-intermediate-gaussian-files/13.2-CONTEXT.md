# Phase 13.2: Temp File Cleanup — Scratch Directory for Intermediate Gaussian Files - Context

**Gathered:** 2026-03-12
**Status:** Ready for planning

<domain>
## Phase Boundary

Move all intermediate Gaussian files (.gjf, .log, .chk, .ipc_file) out of the project working directory into per-run scratch directories under `.scratch/`. Add crash cleanup, stale-dir auto-cleanup on startup, and IPC socket isolation. Both ML frequency and DFT baseline runs use the same mechanism.

</domain>

<decisions>
## Implementation Decisions

### Scratch directory strategy
- Per-run temp subdirectory under project-root `.scratch/` (e.g., `.scratch/run_mace_mp_espaloma_20260312_1430/`)
- Single `.scratch/` at project root, not per-molecule
- Both ML frequency runs (workflow.py) AND DFT baseline runs (dft_baseline.py) use the same scratch mechanism
- Gaussian RWF left to Gaussian's own management (GAUSS_SCRDIR) — not redirected into our scratch dir
- On success: files move from scratch dir to final results location, scratch dir deleted

### Crash cleanup behavior
- Auto-delete entire scratch dir on any failure (crash, timeout, KeyboardInterrupt) via try/finally
- `--keep-scratch` CLI flag on `mace-gaussian run` preserves scratch dir on failure for debugging
- `MACE_KEEP_SCRATCH=1` env var also preserves scratch dir; CLI flag takes precedence
- On startup, auto-delete stale scratch dirs older than 24 hours from `.scratch/`

### CLI integration
- No separate `mace-gaussian clean` command — startup auto-cleanup is sufficient
- `mace-gaussian diagnose` reports stale scratch dirs as part of health check (read-only, no --clean action)

### IPC socket path
- ZMQ `.ipc_file` moves into the per-run scratch directory (no more `.ipc_file` in project root)
- New `MACE_IPC_PATH` env var set before launching Gaussian, helper script reads it to find the socket
- Per-run scratch dirs naturally enable concurrent runs (each has its own IPC socket)

### Claude's Discretion
- Exact naming convention for scratch subdirectories
- Implementation of stale-dir age detection
- How to thread the scratch dir path through workflow.py and dft_baseline.py
- .gitignore updates for `.scratch/`

</decisions>
