    2. Replace the single scatter call (line ~743-752) with a two-group approach:

       After `match_by_mode` returns `dft_freq, ml_freq, dft_int, ml_int, _`, build a confidence mask.
       The challenge: `match_by_mode` remaps mode IDs and returns frequency arrays, losing per-point
       overlap info. However, `match_by_mode` iterates over `matched_modes` (set intersection of
       mode_ids), so we need to reconstruct which original ML mode indices ended up in the matched set.

       Approach: After `match_by_mode` returns, build the mask by iterating through the same
       matched mode set and looking up overlaps. Add a helper that returns matched ML indices
       alongside frequencies. Alternatively, since both `match_by_mode` and the mask-building
       iterate in `sorted(matched_modes)` order, build the mask separately:

       ```python
       # Build per-point confidence mask from mode_overlaps
       confident_mask = np.ones(len(dft_freq), dtype=bool)  # default: all confident
       if mode_overlaps is not None and mode_mapping is not None and len(dft_freq) > 0:
           # Reconstruct which ML mode indices contributed to each matched point
           # match_by_mode iterates sorted(matched_modes) where matched_modes = dft_ids & ml_ids
           # For fundamental modes, ML mode index = int(mode_id[1:]) - 1
           dft_mode_dict = {mode_id: i for i, mode_id in enumerate(dft_spectrum.mode_ids)}
           if mode_mapping is not None:
               # Remapped ML mode IDs (same logic as match_by_mode)
               ml_mode_ids_remapped = []
               for mode_id in ml_spectrum.mode_ids:
                   if mode_id.startswith("F"):
                       ml_mode_num = int(mode_id[1:])
                       ml_idx = ml_mode_num - 1
                       if ml_idx in mode_mapping:
                           dft_idx = mode_mapping[ml_idx]
                           ml_mode_ids_remapped.append(f"F{dft_idx + 1}")
                       else:
                           ml_mode_ids_remapped.append(mode_id)
                   else:
                       ml_mode_ids_remapped.append(mode_id)
               ml_modes_set = set(ml_mode_ids_remapped)
           else:
               ml_modes_set = set(ml_spectrum.mode_ids)

           dft_modes_set = set(dft_spectrum.mode_ids)
           matched_modes = sorted(dft_modes_set & ml_modes_set)

           # For each matched point, find the original ML mode index and look up overlap
           idx = 0
           for mode_id in matched_modes:
               if mode_id.startswith("F"):
                   # This is the DFT-space mode number (after remapping)
                   dft_mode_num = int(mode_id[1:])
                   dft_idx = dft_mode_num - 1
                   # Find which ML mode was mapped to this DFT mode
                   ml_idx = None
                   for k, v in mode_mapping.items():
                       if v == dft_idx:
                           ml_idx = k
                           break
                   if ml_idx is not None and ml_idx in mode_overlaps:
                       if mode_overlaps[ml_idx] < 0.5:
                           confident_mask[idx] = False
               idx += 1
       ```
