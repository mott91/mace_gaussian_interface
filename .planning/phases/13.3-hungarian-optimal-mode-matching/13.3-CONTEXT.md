**Gathered:** 2026-03-15

<domain>
## Phase Boundary

Replace greedy mode matching with `scipy.optimize.linear_sum_assignment` for globally optimal 1-to-1 ML↔DFT mode pairing. Fixes correctness bug where two ML modes can claim the same DFT mode. Improves all regression plots, metrics, and heatmaps before benchmark campaign.

</domain>

<decisions>
## Implementation Decisions

### Unequal mode counts
- Unmatched modes (extras on the larger side) included in results dict as `(None, 0.0)` — not silently dropped
- Reuse existing `create_alignment_matrix()` inside `match_modes()` — no duplication of overlap logic
- Handling of rectangular matrices and negative frequencies: Claude's discretion based on what scipy supports

### Threshold & fallback
- All Hungarian assignments kept in the dict regardless of overlap value
- Low-overlap pairs (below threshold) flagged with `logger.warning` — not dropped
- Default threshold stays at 0.5
- Regression plots show ALL matched pairs; low-overlap pairs use different marker style (open circles) vs confident matches (filled markers)

### Return type
- Keep existing `dict[int, tuple[int | None, float]]` interface — minimal disruption to two call sites in `analysis_workflow.py`
- Single return value (matches dict only) — callers needing overlap matrix already call `create_alignment_matrix()` separately
- Add explicit bijection test: create a scenario where greedy would duplicate-assign but Hungarian gives correct 1-to-1 mapping

### Heatmap annotation
- Draw borders on Hungarian-matched cells: solid border for confident matches (overlap >= 0.5), dashed border for uncertain matches (overlap < 0.5)
- Wire Hungarian matches through to `plot_mode_overlap_heatmap()` at call site in `analysis_workflow.py:612` (currently passes `matches=None`)
- Add small legend explaining border styles (solid = confident, dashed = uncertain)

### Claude's Discretion
- Rectangular matrix handling strategy (scipy's `linear_sum_assignment` supports rectangular natively)
- Whether to filter negative frequencies before matching or keep them
- Exact marker styling for low-overlap pairs in regression plots (consistent with seaborn colorblind palette)
- Border colors and legend placement on heatmap (consistent with existing pastel aesthetic)
- Test coverage approach beyond the required bijection test

</decisions>
