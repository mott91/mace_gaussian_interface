    ```python
    def collapse_alignment_matrix(
        alignment_matrix: np.ndarray,
        groups: list[DegenerateGroup],
        freqs_calc: np.ndarray,
        freqs_ref: np.ndarray,
        matches: dict[int, tuple[int | None, float]],
    ) -> tuple[np.ndarray, list[str], list[str]]:
    ```

    Logic:
    1. Identify grouped ref indices: `grouped_ref = {idx for g in groups for idx in g.ref_indices}`
    2. Identify grouped calc indices: `grouped_calc = {idx for g in groups for idx in g.calc_indices}`
    3. Build ref entries list: each non-grouped ref index becomes one entry labeled `f"{freqs_ref[i]:.0f}"`, each group becomes one entry labeled `f"{g.symmetry_label} @{g.center_frequency:.0f}"` (per D-09)
    4. Build calc entries list: similarly, non-grouped calc indices labeled by frequency, grouped calc indices collapsed into one entry labeled by group
    5. Build collapsed matrix: for non-degenerate x non-degenerate cells, copy from original. For group cells, use group's `subspace_overlap` value. For cross cells (one side group, other not), use max overlap from the sub-block.
    6. Return (collapsed_matrix, calc_labels, ref_labels)

    Also add a new function `plot_collapsed_heatmap()` that wraps `plot_mode_overlap_heatmap()` but accepts collapsed data and custom labels, OR modify `plot_mode_overlap_heatmap()` to accept optional `x_labels` and `y_labels` override parameters. The simpler approach: add `x_labels: Optional[list[str]] = None` and `y_labels: Optional[list[str]] = None` parameters to `plot_mode_overlap_heatmap()`.
