    Per D-03: The `seen_freqs` deduplication in `parse_harmonic_frequencies()` collapses degenerate modes that have identical (freq, intensity) pairs. The fix must preserve degenerate modes within a single frequency block while still deduplicating across repeated frequency blocks (Gaussian prints frequencies twice -- once in initial analysis and once before anharmonic calculation).

    **Implementation (per Pitfall 3 in RESEARCH.md):**

    Replace the `seen_freqs` set approach with a block-aware deduplication:

    1. Track a `block_index` counter that increments each time a new "Frequencies --" line is found
    2. Change the dedup key from `(round(freq, 4), round(intensity, 4))` to `(round(freq, 4), round(intensity, 4), block_index)`
    3. This way: within a single block, degenerate modes with identical freq+intensity ARE kept (different block_index); across repeated blocks, the same freq+intensity+block combination IS deduplicated

    Wait -- that still won't deduplicate across blocks. The real issue is simpler:

    Actually, use a different approach: track `seen_blocks` as a set of tuples-of-tuples representing entire frequency blocks. Or more simply:

    1. Collect ALL frequencies from ALL blocks into a list of lists (one inner list per block)
    2. If two blocks are identical (same set of freq+intensity pairs in same order), keep only the first
    3. Flatten the surviving blocks into the final frequency list

    Concrete implementation:
    ```python
    def parse_harmonic_frequencies(self) -> list[dict[str, float]]:
        all_blocks = []  # list of lists of (freq, intensity) tuples
        lines = self.content.split("\n")
        i = 0
        while i < len(lines):
            line = lines[i]
            if "Frequencies --" in line:
                freq_match = re.search(freq_pattern, line)
                if freq_match:
                    freqs = [float(x) for x in freq_match.group(1).split()]
                    for j in range(i + 1, min(i + 10, len(lines))):
                        if "IR Inten" in lines[j]:
                            ir_match = re.search(ir_pattern, lines[j])
                            if ir_match:
                                intensities = [float(x) for x in ir_match.group(1).split()]
                                block = list(zip(freqs, intensities))
                                all_blocks.append(block)
                            break
            i += 1

        # Deduplicate repeated blocks (Gaussian prints freq section twice for anharmonic)
        # Keep first occurrence of each unique block
        seen_block_keys = set()
        frequencies = []
        for block in all_blocks:
            block_key = tuple((round(f, 4), round(i, 4)) for f, i in block)
            if block_key not in seen_block_keys:
                seen_block_keys.add(block_key)
                for freq, intensity in block:
                    frequencies.append({"freq_cm": freq, "ir_intensity": intensity})

        if not frequencies:
            raise GaussianParseError(...)
        return frequencies
    ```
