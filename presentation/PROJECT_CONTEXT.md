## What this project is

A research presentation for group meetings and thesis defense, built entirely
from a Python script that generates a `.pptx` file programmatically. No
PowerPoint editing — all content lives in code, all changes go through git.

**Presentation topic:** ML-accelerated IR spectroscopy (MACE-Gaussian Interface)
**Author:** Manuel Ott · Hofer Lab
**Audience:** Computational + theoretical chemists, some life scientists
**Target length:** ~15 minutes

## Key results to reference

**Water (H₂O) — 3 modes, anharmonic VPT2:**
- Best: mace_anicc + espaloma → MAE 16.8 cm⁻¹, R² 0.9999
- Good: mace_off + espaloma → MAE 33.2 cm⁻¹, R² 0.9999
- Worst: mace_mp + espaloma → MAE 129.9 cm⁻¹, R² 0.9971
- Intensity R² low across all combinations (< 0.15) — known open problem

**Aspirin (C₉H₈O₄) — 51 modes, harmonic:**
- mace_omol + espaloma → MAE 41.3 cm⁻¹, R² 0.9984, ~18× speedup
- Method scales: water 1×, aspirin 18× — advantage grows with molecule size

## How changes work

1. Edit `generate_pptx_v2.py`
2. Run `python presentation/generate_pptx_v2.py`
3. Open `presentation_v2.pptx` to review
4. Commit both `.py` and `.pptx` when happy

The `.py` file is the source of truth. The `.pptx` is a build artifact committed
for convenience (so the file is downloadable from GitHub without running the script).

## Science context (for slide content decisions)

The broader project (MACE-Gaussian) is a Python package that bridges ML potentials
(MACE) with Gaussian 16 for computing molecular IR spectra via VPT2. The thesis
question is: **does energy surface quality or dipole model quality dominate IR
accuracy?** This is being answered by a systematic ~25-molecule benchmark.

Key claim: frequencies work well (R² > 0.998), intensities don't (R² < 0.15).
This is not a bug — it's a research finding worth highlighting.
